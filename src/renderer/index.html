    Machines that asked to boot

      Boot files & troubleshooting
      • Turn Secure Boot off on the machines you want to install (the iPXE loader is not signed).
      • Ubuntu downloads the whole ISO into memory: the machine needs more RAM than the ISO size + 1 GB.
      • macOS/Windows may ask to allow incoming connections the first time — choose Allow.
      • Raspberry Pi boards don’t use PXE like PCs; they need UEFI firmware on an SD card first.
